# Neovim — шпаргалка

Минимальный конфиг в стиле базового VS Code: тема Tokyo Night, файловый сайдбар,
LSP, автодополнение, поиск по проекту, git-хунки и встроенный терминал.

Конфиг лежит в `config/nvim` (симлинк `~/.config/nvim`), плагины — `vim.pack`,
список только в `lua/plugins.lua`.

## Как читать клавиши

| Запись | Что нажимать |
|---|---|
| `<leader>` | **Пробел** |
| `<C-l>` | **Ctrl + L** (латинская «эль») |
| `<S-l>` | **Shift + L** (заглавная L) |
| `<C-\>` | **Ctrl + \\** (обратный слэш) |
| `<Esc><Esc>` | **Esc** два раза подряд |
| `:bd` | набрать в командной строке `:bd` и Enter |

Если нажать **Пробел** и подождать ~0.4 с, which-key покажет меню доступных
хоткеев (Поиск, Буферы, Git, Код).

## Запуск и выход

| Действие | Клавиши |
|---|---|
| Открыть Neovim | `nvim` |
| Открыть файл | `nvim файл` |
| Сохранить | `<leader>w` (`:w`) |
| Сохранить и выйти | `:wq` или `ZZ` |
| Выйти | `:q` (в окне редактора закрывает Neovim целиком) |
| Выйти без сохранения | `:q!` или `:qa!` |
| Выйти из любого окна | `<leader>q` (`:qa`) |

Во встроенном терминале `Esc` не выходит из режима вставки — используй
`<Esc><Esc>`.

## Окна и сайдбар

Сайдбар — обычное окно Neovim, переключаться можно как между любыми сплитами.

| Действие | Клавиши |
|---|---|
| Открыть/свернуть сайдбар | `<leader>e` |
| В редактор из сайдбара | `<C-l>` |
| В сайдбар из редактора | `<C-h>` |
| Окно ниже / выше | `<C-j>` / `<C-k>` |
| Следующее окно | `<C-w>` + `w` |
| Закрыть окно | `:q` |
| Оставить только текущее окно | `<C-w>` + `o` |

После `:bd` окно редактора не исчезает: справа от сайдбара остаётся пустая
рабочая область, сайдбар сохраняет ширину 32.

## Вкладки = буферы

Полоска сверху — это открытые буферы (рисует lualine). Клик мышью работает.

| Действие | Клавиши |
|---|---|
| Следующая вкладка | `<S-l>` (Shift + L) |
| Предыдущая вкладка | `<S-h>` (Shift + H) |
| Список буферов с поиском | `<leader>fb` |
| Закрыть текущую вкладку | `<leader>bd` или `:bd` |
| Закрыть без сохранения | `<leader>bD` или `:bd!` |

Важно:

- `<leader>bd` и `:bd` закрывают **буфер**, но не окно и не Neovim: справа
  от сайдбара остаётся пустая рабочая область.
- Пустая область не появляется в полоске вкладок и не плодит новых пустых
  вкладок. Как только в ней что-то набрали — вкладка появляется.
- Если в буфере есть несохранённые изменения, `:bd` откажет. Закрыть
  принудительно — `<leader>bD` или `:bd!`.
- В Neovim нет отдельных «вкладок-раскладок» как в VS Code. `:tabnew` создаёт
  отдельную вкладку Neovim (другой набор окон), но обычно она не нужна.

## Файловый менеджер (neo-tree)

| Действие | Клавиши |
|---|---|
| Открыть файл / папку | `Enter` |
| Открыть в вертикальном сплите | `s` |
| Открыть в горизонтальном сплите | `S` |
| Создать файл | `a` |
| Создать папку | `A` |
| Переименовать | `r` |
| Удалить | `d` |
| Копировать | `y` |
| Вырезать | `x` |
| Вставить | `p` |
| Дублировать | `c` |
| Переместить | `m` |
| Обновить дерево | `R` |
| Показать скрытые файлы | `H` |
| Помощь по клавишам | `?` |
| Закрыть сайдбар | `q` |

Точки (`.git`, `.gitignore` и т.п.) видны, а файлы из `.gitignore` скрыты.

## Поиск по проекту (telescope)

| Действие | Клавиши |
|---|---|
| Найти файл | `<leader>ff` |
| Поиск текста (grep) | `<leader>fg` |
| Открытые буферы | `<leader>fb` |
| Справка Neovim | `<leader>fh` |

В окне поиска:

- `Ctrl+N` / `Ctrl+P` или стрелки — выбор;
- `Enter` — открыть;
- `Ctrl+V` — открыть в вертикальном сплите;
- `Ctrl+X` — в горизонтальном;
- `Esc` — закрыть;
- `Ctrl+/` — помощь по picker'у.

Для `<leader>ff` и `<leader>fg` нужен `ripgrep`:

```bash
sudo apt install -y ripgrep
```

Без него поиск файлов и текста работать не будет.

## LSP и работа с кодом

Серверы: `lua_ls`, `bashls`, `pyright`, `ts_ls`, `clangd`, `rust_analyzer`,
`jsonls`, `yamlls`, `html`, `cssls`, `emmet_language_server`, `intelephense`
(PHP). Go (`gopls`) отложен.

| Действие | Клавиши |
|---|---|
| К определению | `gd` |
| К объявлению | `gD` |
| Ссылки | `gr` |
| Реализации | `gi` |
| Документация | `K` |
| Переименовать | `<leader>rn` |
| Действия кода | `<leader>ca` |
| Форматировать | `<leader>f` (Пробел → F, подождать) |
| Диагностика строки | `<leader>cd` |
| Следующая / предыдущая ошибка | `]d` / `[d` |

Диагностика показывается виртуальным текстом (`●`), подчёркиванием и знаками
на полях.

Управление серверами:

- `:Mason` — список и установка LSP-серверов;
- `:checkhealth lsp` — проверка состояния LSP;
- `:checkhealth` — общая проверка Neovim.

## Автодополнение (blink.cmp)

| Действие | Клавиши |
|---|---|
| Принять подсказку | `Tab` |
| Следующий / предыдущий вариант | `Down` / `Up` или `Ctrl+N` / `Ctrl+P` |
| Открыть меню вручную | `Ctrl+Space` |
| Скрыть меню | `Ctrl+E` |
| Прокрутить документацию | `Ctrl+B` / `Ctrl+F` |
| Показать/скрыть сигнатуру функции | `Ctrl+K` |

`Enter` в этом режиме **не** принимает подсказку — он переносит строку.
Документация к варианту показывается автоматически через 300 мс.
Источники: LSP, пути файлов, слова из буфера, сниппеты.

## Git (gitsigns)

| Действие | Клавиши |
|---|---|
| Следующий / предыдущий хунк | `]c` / `[c` |
| Застейджить хунк | `<leader>gs` |
| Сбросить хунк | `<leader>gr` |
| Посмотреть хунк | `<leader>gp` |
| Blame строки | `<leader>gb` |
| Diff текущего файла | `<leader>gd` |

Знаки на полях: `▎` — добавлено/изменено, `▏` — удалено.
Lazygit в конфиге нет — только gitsigns.

## Терминал

| Действие | Клавиши |
|---|---|
| Открыть / скрыть терминал | `<C-\>` |
| Выйти из режима вставки терминала | `<Esc><Esc>` |
| Вернуться в терминал | `i` (в нормальном режиме терминала) |
| Переключиться в редактор | `<C-h>` / `<C-k>` |

Терминал открывается снизу и переиспользует один и тот же буфер.

## Синтаксис и тема

- Подсветка — treesitter, парсеры ставятся автоматически при первом запуске.
- Тема — `tokyonight-night`: фон `#1a1b26`, текст `#c0caf5`.
- Сайдбар темнее (`#16161e`), статуслайн `#1f2335`.
- Дополнительные парсеры: `:TSInstall <язык>`, обновление — `:TSUpdate`.

Для treesitter нужен `tree-sitter` CLI ≥ 0.26.1. В этом репозитории он ставится
`scripts/install.sh` в `~/.local/bin/tree-sitter`.

## Плагины

Список — только `lua/plugins.lua`, менеджер — встроенный `vim.pack`.

| Действие | Команда |
|---|---|
| Обновить все плагины | `:lua vim.pack.update()` |
| Перезапустить Neovim после обновления | `:restart` |
| Проверить здоровье | `:checkhealth` |

Версии зафиксированы в `nvim-pack-lock.json`. Lock-файл руками не править.
Обновление только вручную, автоматических обновлений нет.

## Изменения конфига

Правка файлов в `config/nvim` сразу меняет `~/.config/nvim` (симлинк).

- Изменения в Lua-модулях — после перезапуска `nvim`.
- Текущий файл можно применить через `:source %`.
- Настройки плагинов и `init.lua` лучше проверять перезапуском.

## Частые проблемы

| Симптом | Решение |
|---|---|
| `<leader>ff` / `<leader>fg` не ищут | `sudo apt install -y ripgrep` |
| Нет подсветки синтаксиса | `:TSUpdate`, проверить `tree-sitter --version` |
| LSP не подключился | `:checkhealth lsp`, `:Mason` |
| Пустая вкладка после закрытия файла | Её нет: пустая область не показывается в полоске — так и задумано |
| После `:bd` пропал файл, но не окно | Так и должно быть: окно остаётся для следующего файла |
| `:q` не вышел из Neovim | `:q` закрывает то окно, где нажат: в сайдбаре он закроет сайдбар. Из любого окна выходит `<leader>q` |
