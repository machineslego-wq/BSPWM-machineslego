## Суть

Главный принцип — **надёжность, универсальность и визуальная целостность**.

Отсутствие сложных bash-скриптов для управления системами в пользу стоковых (встроенных) модулей Polybar, которые работают на C++ и не потребляют ресурсы. 

**Polybar отвечает только за индикацию.** Всё управление (Wi-Fi, звук, питание) вынесено на горячие клавиши и вызовы терминальных утилит. Это исключает конфликты и поломки при смене оборудования или обновлении системы.

## Глобальный редизайн (Что нового)

Полностью переработана визуальная часть окружения:

- **Новый Polybar:** Теперь за место квадратного дизайна и непонятного интерфейса панель поделенная на блоки со скруглениями. Активный рабочий стол теперь выделяется аккуратным подчеркиванием, а индикатор яркости заменен на стильные точечные маркеры (`●○○○○`).
- **Унифицированный Rofi:** Лаунчер, меню питания и шпаргалка теперь имеют единый стиль: глубокий фон, аккуратные скругления, синие акценты Tokyo Night и красивые иконки приложений.
- **Центр уведомлений (Dunst):** Всплывающие окна получили поддержку группировки, цветовое кодирование (от красного ЭкритическогоЭ до синего ЭобычногоЭ), полосы прогресса (для громкости) и красивые отступы.
- **Строгий терминал:** Alacritty полностью непрозрачен - это дает идеальную читаемость и профессиональный вид.

## Особенности

- **Native Modules First:** Для батареи, сети и звука используются стоковые модули `internal/battery`, `internal/network`, `internal/pulseaudio`.
- **Отказ от прозрачности:** Убраны все эффекты прозрачности и размытия (в Alacritty, Polybar и Picom). Это снижает нагрузку на видеокарту и делает интерфейс строже.
- **Затемненные обои:** Оригинальные обои затемняются через ImageMagick и подкрашиваются в цвет фона панели (`#1a1b26`), чтобы глаза не уставали, а интерфейс выглядел монолитно.
- **Статичная шпаргалка:** Меню `Super + /` — это красивый статичный список с иконками и скрытыми тегами для мгновенного поиска (работает через Rofi).
- **Универсальное железо:** Переменные окружения в `launch.sh` (автоопределение `BAT0`/`BAT1`, `AC`/`ADP1`) позволяют конфигу работать на разных ноутбуках без правок.
- **Управление без апплетов:** Отказались от `nm-applet` и `pasystray`. Wi-Fi — через `nmtui`, звук — через `pavucontrol`.

## 🛠 Установка

### Шаг 1. Клонирование и запуск
```bash
git clone https://github.com/machineslego-wq/BSPWM-machineslego ~/BSPWM-machineslego
cd ~/BSPWM-machineslego
chmod +x scripts/*.sh
./scripts/install.sh
```
Установщик сам скачает шрифты, установит пакеты, настроит `sudoers` для питания и создаст нужные симлинки. 
*Если системные файлы в `/etc` менять не нужно, используйте `./scripts/link.sh`.*

### Шаг 2. Запуск
```bash
startx
```

## 🖼️ Обои и тема

Чтобы обои не выделялись, они **затемняются и подкрашиваются** в базовый цвет темы (`#1a1b26`) через ImageMagick:

```bash
convert /path/to/original_wallpaper.jpg -fill "#1a1b26" -colorize 50% -modulate 80,80,100 /path/to/tokyo-night-wallpaper.jpg
```

## ⌨️ Горячие клавиши и шпаргалка

**Как открыть:** Нажмите **`Super + /`** (слэш). Откроется меню Rofi со всеми комбинациями, иконками и цветными заголовками. Поиск работает по скрытым тегам (начните печатать "окно", "скрин" или "звук").

### Управление системами (без апплетов)

**1. Wi-Fi и Звук**
- Сети: `nmtui` в терминале.
- Звук: `pavucontrol` (микшер) или горячие клавиши `XF86Audio...`.
- *Индикация:* стоковые модули Polybar `[module/wlan]`, `[module/eth]`, `[module/pulseaudio]`.

**2. Питание**
- **Ноутбук (TLP):** Клик по модулю в Polybar открывает меню Rofi.
- **Ноутбук (GNOME/PPD):** Используется `power-profiles-daemon`.
- **ПК:** Управление через Polybar не настраивается.

**3. Скриншоты**
Снимки (`Print`, `Shift+Print`, `Super+Shift+S`) сохраняются в `~/Изображения/Screenshots/` и **сразу копируются в буфер обмена** (через `xclip`).
